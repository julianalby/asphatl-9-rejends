# About the Project
This was a prototype I developed for my Human and Computer Interaction Lab Project, built using HTML, CSS, and Javascript. It showcases a game called **Asphatl 9 Rejends**, a parody of the mobile racing game **Asphalt 9 Legends**. <ins>The project is for educational purposes only and is in no way affiliated with the official Asphalt 9 Legends and is not a real game.</ins>

The website consists of 5 pages:
- **Home**: The website's landing page, containing the game's tagline, a single screenshot, and download buttons which all link to their respective store page of Asphalt 9 Legends.
- **Gallery**: Showcases the game's cars all the way from S Class to D Class, with 4 cars shown per class.
- **News**: Shows the latest news for the game, displaying each article's title, upload date, and reading time.
- **Esport**: Shows information about the game's tournaments, including its trailer, number of tournaments held, number of participants, prize money, total races, and sponsors.
- **Subscription**: A login form with 5 validation rules; username must be 3-15 characters, email must end with @gmail.com, date of birth must be selected, gender must be selected, and the terms and conditions checkbox must be checked.

# How to run in Visual Studio Code
1. Open Visual Studio Code, if not installed, download from https://code.visualstudio.com/
2. Go to **Extensions** (Ctrl + Shift + X)
3. Install **Live Server** by Ritwick Dey
4. Click **File**, then **Open Folder**
5. Open the "**asphatl-9-rejends**" folder
6. Right click on "**home.html**"
7. Select **Open with Live Server**
8. The website should automatically open on your default browser
